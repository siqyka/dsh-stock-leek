# dsh-stock-leek

**npm 包名 [`@shiqyka/dsh-stock-leek`](https://www.npmjs.com/package/@shiqyka/dsh-stock-leek) · 把大盘指数、自选股与持仓盈亏，直接嵌进 DSH 对话界面。**

不用离开 DSH，也不用再开一个行情软件。

[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) Web 端的股票行情插件：

- **对话左下角常驻大盘指数栏**（上证 / 深证 / 创业板 / 恒生 / 纳斯达克…，自选要显示哪几个）
- **可拖动行情悬浮窗**：大盘 · 自选 · 持仓 · 设置 四页 + 个股分时 / K 线详情
- **自选股**：搜索（代码 / 名称 / 拼音首字母）添加，A 股 · 北交所 · 港股 · 美股 · ETF · 指数全覆盖
- **持仓股**：填成本价 + 股数，并可逐笔记录**买卖变动**（买入 / 卖出，支持当日多次），实时算市值 / 累计盈亏 / **今日盈亏（按当日变动现金流计算）** / 总盈亏汇总

数据源为腾讯财经公开行情接口（`qt.gtimg.cn` / `web.ifzq.gtimg.cn` / `smartbox`），红涨绿跌。

## 安装

```bash
# 本地目录（把 <path> 换成你自己 clone 的位置）
dsh plugin --profile desktop add file:<path>/dsh-stock-leek
# 或发布后按包名（npm scoped 包，DSH 插件管理器自动识别）
dsh plugin add @shiqyka/dsh-stock-leek
```

安装后**刷新页面**生效。对话输入框下方出现指数栏，点任意指数胶囊打开悬浮窗，点 `⚙` 直达设置。

## 功能

| 位置 | 能力 |
|---|---|
| 对话左下角 | 大盘指数胶囊：简称 + 点位 + **相对昨收的涨跌点数**（带正负号）+ 涨跌幅，价格变动红/绿闪烁；盘中状态点；点胶囊开悬浮窗、`⚙` 直达设置。有持仓时显示 **💰收益** 胶囊（今日盈亏），**鼠标悬停弹出浮层**：市值 / 累计收益（额+率）/ 今日收益（额+当日涨幅%）+ 每只持仓的**今日盈亏与当日涨幅**（累计、成本、市值等明细在行悬浮提示）。**非交易时段自动收起**——收盘后指数和收益都只是昨天的数字，只留「状态点 + ⚙ 设置」（点状态点可进大盘页）；**每天 9:00–15:06 自动展开**，其余时间只留「状态点 + ⚙ 设置」；**点 ● 可手动收起/展开**（展开→收起、收起→展开），手动选择持续到下一个交易日自动失效；**午休不收起**（按整个交易日跨度判断，不会 11:30–13:00 凭空消失）。样式（点位+涨跌 / 仅涨跌）、对齐（左/中/右）、显隐均可配。**指数栏关掉后的兜底入口**：侧栏「插件 → @shiqyka/dsh-stock-leek」页里有一张带边框的「指数栏」配置卡片（走宿主的 `plugins.bundle.config` keyed 槽位，key = 包名）——「指数栏」标题 + 「运行中 / 已关闭」状态徽标 + 右侧一个**胶囊开关**（与宿主列表行同款：36×20 轨道 + 16×16 圆点，旁边带「已开启 / 已关闭」文字）—— 指数栏一收起来，悬浮窗和设置就都在它里面、界面上再没有别的入口，这个页面是唯一永远可达的地方。**放置方式二选一**：① 悬浮锚定（默认）——自动跟随对话输入区左下角、可拖动，新会话页与已有对话都显示；**切到插件 / 远程工作区等没有输入区的面板时留在原地不跳**（记住上次测得的位置，关掉面板回来再跟上）；② 嵌入输入框——作为平台 `conversation.composer.dock` 槽位内容，**排在右侧「上下文占用」指示之后**（该槽位与它是同一个 flex 行里的兄弟节点，靠自身 `order:1` 实现，不需改宿主），仅「已有对话」显示（新会话页该槽位宿主按平台源码不渲染，属平台限制） |
| 悬浮窗·大盘 | 候选指数列表：**按住行首 ⠿ 左键拖动排序**（实时落点指示线），勾选是否显示到左下角、删除、搜索添加新指数（含港/美/北指数）。**超过 10 条时列表内部出现滚动条**，表头与搜索框始终可见。**底部栏显示涨跌家数与成交额**：涨跌家数取沪深北三地合计（如数字 + 红绿对半的强弱条，宽度=上涨占比），大A成交额为沪深北三指数成交额之和；两项独立可用，其中一个源挂了只隐藏那一项 |
| 悬浮窗·标题 | **彩蛋**：标题随今日盈亏「变脸」——无持仓/持平 → 📈 观望中 · 盈利 → 🍗 加鸡腿（≥3% 🚀 起飞了）· 亏损 → 🍜 关灯吃面（≤−3% 🧘 天台吹风）。鼠标悬停标题可查看今日实际盈亏额 |
| 悬浮窗·标题栏 | **⏱ 数据新鲜度徽标**：显示「距上次成功拿到行情已过 N 秒」，自带 1s 走秒（正计时，越大越旧）。悬停显示更新时长与当前刷新间隔。超过 2 个刷新周期（且至少 12s）未更新即标黄，提示可能休市或推送中断，可点右侧 ⟳ 手动刷新。尚未拿到数据时显示 `⏱—` |
| 悬浮窗·自选 | 实时列表（现价 / 涨跌幅 / 涨速 / 成交额 / 换手，价格变动闪烁），**⠿ 拖动排序**，点击进详情，搜索添加，删除。超过 10 条同样内部滚动 |
| 悬浮窗·持仓 | 每只填 **成本价 + 股数**（**⠿ 拖动排序**，超 10 只内部滚动）。右键 **⇅ 记一笔交易** 展开抽屉**只放录入表单**（买入/卖出 + 价格 + 股数 + 日期，当日可多笔，卖出自动减持仓）；右键 **📒 交易记录** 进二级页看该股全部成交（方向/日期/价格/股数/金额，最新在前，带买/卖/净股数汇总与「今」标记，可逐笔删除，只显示被右键那只；**超 10 笔内部滚动**）。实时显示现价/涨跌、**累计盈亏（额+率）**、**今日盈亏**；顶部汇总市值 / 今日 / 累计，**下方可展开「今日盈亏走势」曲线**（**并标注当日盈亏的最高/最低金额**，带正负号与万/亿量级）（把每只持仓的今日盈亏按分钟展开，零轴=不赚不亏，能看出今天几点开始赚/亏；**按设置的刷新间隔跟随行情更新**（曲线形状按 tick 重取，末端实时价每次推送都接上），与上方今日盈亏始终对得上；**收起/展开状态记在配置里**，切标签页、切股票、重启浏览器都保持）。**今日收益按当日买卖现金流计算**：`当前持仓×现价 + 今日卖出额 − 今日买入额 − 昨日持仓×昨收`（无当日交易时退化为 `(现价−昨收)×股数`）。**今天才建立的持仓改按成本算**（`(现价−成本)×股数`）：直接填成本+股数建仓时没有流水，光看"无当日变动"分不清「昨天就持有」和「今天刚买」，按昨收算会凭空多出一段浮盈（实测：成本 52.435 / 现价 52.390 / 昨收 52.310 时曾显示今日 +80，真实是 −45）。建仓当天记下 `openedAt`（行情日期口径），次日自动回到昨收口径。**成本由流水重算**：`当前持仓 = 基准持仓 + 修正点之后的流水`，记一笔/删一笔都从同一函数重算，不会像增量公式那样越算越偏；**在几笔交易之后回头改成本/股数**时，那次修改等于宣告"此刻持仓就是这样"，之前的流水被吸收、不再叠加（`baseAt` 记修正时刻），之后记的流水照常叠加。**清仓不丢收益**：卖光后该股仍保留在持仓里，今日已实现盈亏继续计入汇总，累计盈亏按 `今日卖出额 − 今日买入额 − 昨仓×成本` 接住、在清仓瞬间保持连续（不会跳成 0），悬浮明细里该行标注「已清仓」。**下一个交易日自动移除**：判据用行情日期而非本地日期，因此周末与节假日不会误删，要等真正进入下一个交易日才清理 |
| 悬浮窗·详情 | 分时折线（昨收基准线，**并标注当日最高/最低点的数值**：极值处画小圆点 + 价格文字，取当日第一个极值点）/ 日K·周K·月K 蜡烛（MA5/10/20/60 可切，**左上角显示对应 MA 数值并跟随选中 K 线变化**；**MA 选择存于全局配置，跨股票/周期/会话保持**（host 回填配置时若丢失该字段会保留本地值，避免选择弹回默认），MA5 用主题色随昼夜切换）/ 关键指标；**持仓股额外画出成本线**（虚线 + 右侧「成本 x」标签，跌破成本转红，成本价会被纳入价格范围因此远在区间外也可见，详情头部同步显示成本徽标）/ **K 线支持滚轮缩放 + 拖动平移 + 底栏复位**（以鼠标位置为锚点，底部显示可视区间与根数，换股票/周期自动复位）；**悬浮预览、点击钉住单根 K 线**（带十字光标与右侧价格标签），**顶部指标区随之切换**：选中时显示该根的日期/开高低收/涨跌/量/振幅，不选中则显示当日行情；双击图表或点空白处取消钉住；**钉住后可用 ← / → 逐根切换**（到数据边界不越界，切出可视窗口时图表自动跟随，输入框内不抢按键）。**日/周/月K 的最后一根盘中随行情更新**（跟随刷新间隔重拉，收出开盘后"今天那根"会实时长出来）。**图表下方有五档盘口**（**只在分时视图显示**：盘口是此刻的撮合队列，与分时同属实时视角；切到日/周/月K 时隐藏），两种布局一键切换：**左右结构**（默认，左卖右买，两列都从贴近现价的一档往下排：卖1→卖5 / 买1→买5）/ **上下结构**（券商惯例：卖5→卖1 在上、现价居中、买1→买5 在下）。每档显示价格与挂单量、横条按当前口径占十档最大值的比例画；右上角**委比**，并支持**手数 / 金额 一键切换**（金额 = 挂单价 × 股数）。两个切换都**写进全局配置**（`bookLayout` / `bookUnit`），跨股票、跨重开保持。**集合竞价时段（9:15–9:25 / 14:57–15:00）显示「集合竞价」而非五档**：沪深交易所在竞价阶段不披露委托明细，接口此时给的是虚拟匹配价 + 可匹配量（表现为买卖各 1 档、同价同量、今开仍为 0），直接画成买一/卖一会被误认成真实挂单簿；开盘后自动切回五档。数据取自行情快照本身（同一份响应，零额外请求），跟随刷新间隔一起更新 |
| 悬浮窗·设置 | 指数栏显隐/样式/位置、刷新间隔（3~60s）、涨跌配色、**测试数据源**、**🔔 预警**（二级页）、恢复默认；**配置损坏告警常驻条**（见「配置安全」） |
| 设置 · 预警（二级页） | 规则管理（8 种条件：现价上/下穿、突破/跌破成本、涨幅/跌幅达标、接近涨跌停、涨速达标；**成本类自动取持仓成本价**）+ 总开关 + 桌面通知开关。规则**按股票代码分组抽屉**——同一只票的多条规则收在一组，组头常驻显示「名称 + 代码 + 条数 + 已触发数」并带 `▸/▾` 展开箭头，手风琴单开（展开一组自动收起另一组）；新加规则自动展开对应组，不会藏进收起态；**超 10 组内部滚动**（按组计数，不是按规则条数）。**规则没有「停用」一说：存在即评估，删除就是停用**（列表里有它就一定会响，不会出现"看得见却永远不响"的规则）。**评估在 Host 独立循环**——关掉页面也会照常评估。自选/持仓行右键「🔔 设为预警」可预填现价/成本价快速建规则。设计依据与验收见 [docs/alerts-plan.md](docs/alerts-plan.md) |
| 预警弹窗 | 触发时在**对话区顶部居中**弹出（**与悬浮窗开关无关**：关着悬浮窗照样弹）。**同一时间最多 3 条**，再多则叠加到最早那条并显示 `+N`；**10 秒自动消失**，也可点 `✕` / `Escape` / 「全部关闭（N）」手动关。倒计时**只在页面可见时走**（隐藏时冻结），避免你不在时悄悄过期。另外不弹 toast（弹窗已足够醒目）、**不记录触发历史** |

### 预警行为

- **每交易日每规则只提示一次**：触发过就不再重复，即使价格回落再涨回；次日（按**行情时间戳的市场本地日**判定，美股不会在北京时间 00:00 被误重置）重新生效。
- **休市/节假日不评估**：按 code 逐个判断交易时段，且要求「报价日 == 该市场本地当日」——休市时报价停在上一个交易日，条件可能恒真，必须跳过，否则每逢节假日误报一次。
- **缺数据宁可不报**：无时间戳、成本缺失（持仓已清仓）、港美股用「接近涨跌停」等情形一律跳过。
- **零成本休眠**：没有任何规则 / 总开关关闭 / 全市场休市 → 评估循环退避，**一次上游请求都不打**。

## 配置

配置以 **Host 文件为准**（`~/.dsh/dsh-stock-leek/config.json`），浏览器 `localStorage` 仅作首屏缓存。写入前自动备份 `.bak`；解析失败时保留 `.corrupt` 现场并回退备份，**不会静默吞掉持仓**；多标签页通过 `BroadcastChannel` 同步并用版本号检测冲突。

预警的规则状态（判断「今日是否已提示过」）单独落盘 `config.json.alerts`（**与配置分文件**：评估循环高频读写，不该每次都重写配置、搅动 `__rev` 乐观锁；路径派生自配置路径，因此测试的 pid 隔离自动继承）。该文件**只存状态、不存触发历史**——历史已按要求去掉，`states` 必须保留，否则 Host 重启后会重复播报。

字段清单、旧路径搬迁、持仓与预警规则结构、代码归一化规则 → **[docs/configuration.md](docs/configuration.md)**

## 架构

```
浏览器（client.js）
  ├─ conversation.composer.dock → 左下角指数栏（IndexBar）
  ├─ shell.overlay              → 悬浮窗（大盘/自选/持仓/设置 + 预警二级页/详情）
  ├─ 共享 store：配置 + 行情快照 + SSE/轮询双通道（页面隐藏自动暂停）
  ├─ 预警流 /alert-stream：**隐藏时保持连接**（触发稀疏、零上游请求）
  └─ 自绘 SVG 分时 / K线 / 盈亏曲线（零 CDN 依赖）
        │ fetch 同源 /dsh-stock-leek/*
        ▼
Host（index.js，cordis 插件，依赖 webServer）
  ├─ /config  GET/POST  读写配置（含首屏行情快照、版本号、损坏告警）
  ├─ /stream  SSE 行情推送（多标签页共用一次拉取）
  ├─ 预警评估循环：与订阅者无关，无规则/休市自动休眠
  ├─ /alerts  GET  规则状态（客户端重连后对账；不返回触发历史）
  ├─ /alert-stream  SSE 预警推送（独立订阅集合，不参与行情广播开关）
  ├─ /quotes  批量实时行情（qt.gtimg.cn，GBK，1.5s TTL + 单飞去重）
  ├─ /minute  分时   /kline 日/周/月K(前复权)   /search 全市场搜索
  └─ /probe   数据源连通性自检
        ▼
  ~/.dsh/dsh-stock-leek/config.json         ← 自选/持仓/指数栏/预警规则持久化（换浏览器不丢）
  ~/.dsh/dsh-stock-leek/config.json.alerts  ← 预警规则状态（今日是否已提示；只存 states）

lib/shared.js（纯函数，Host 与测试共用）
  格式化（价格/百分比/金额/成交量/时间/代码）+ 盈亏口径（todayPnl 等）
```

## 安全设计

插件的全部外部输入是「股票代码」与「搜索词」，攻击面集中在四处，均已加固并有回归测试锁定：

| 面 | 威胁 | 防护 |
|---|---|---|
| **URL 拼接** | code 拼进 `qt.gtimg.cn` / 东财接口，若含 `?#/&=空格` 可逃逸查询参数、追加参数 | `normalizeApiCode` 先剥掉所有非 `[A-Za-z0-9_.$]` 字符，输出绝不含 URL 结构字符（18 组攻击输入对拍） |
| **配置 POST** | 原型污染、超长 code、负成本、颜色/CSS 注入、超大 body | 白名单式清洗：code≤16、cost/qty 非负钳制、颜色只收 `#hex`、列表≤300、txns≤200、body≤2MB、`__proto__`/`constructor` 无效 |
| **XSS** | 股票名来自上游，可能含 HTML | 全部经 React 渲染（自动转义），无 `innerHTML`/`dangerouslySetInnerHTML`/动态 `href`/`style`；零硬编码外链 |
| **SSE 注入** | 恶意股票名伪造 SSE 帧边界 | `JSON.stringify` 把 `\n` 转为字面量，帧边界只有帧尾一个真实 `\n\n`，端到端验证首推恰 1 帧 |

其它：`package.json` 零依赖（无供应链面）；配置落盘 `~/.dsh/dsh-stock-leek/`，写入走「备份 + 临时文件 + 原子 rename」，解析失败另存 `.corrupt` 并尝试回退 `.bak`，绝不静默用默认值覆盖用户持仓。
